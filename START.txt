=========================================================
   AI大模型管理系统 - 快速启动指南
=========================================================

一、快速启动（推荐）
-------------------
1. 安装Django（如果未安装）：
   py -m pip install Django==5.0.1

2. 初始化数据库和测试数据：
   py init_and_run.py

3. 启动服务器：
   py run_server.py

4. 打开浏览器访问：
   http://127.0.0.1:8000/

5. 使用测试账户登录：
   用户名: admin
   密码: admin123456

   或

   用户名: testuser
   密码: test123456

=========================================================

二、功能说明
-----------
✓ 用户注册和登录（Session状态保持）
✓ AI模型增删改查（包含多种数据类型）
✓ 模型类型管理（外键表，支持级联删除）
✓ 关键字模糊搜索
✓ 按模型类型过滤查询
✓ 分页显示（每页10条）
✓ 导出CSV功能
✓ 美观的Tailwind CSS界面
✓ 权限控制（未登录只能查看）

=========================================================

三、项目特色
-----------
• 使用Django装饰器（@login_required_with_message等）
• Session状态保持（24小时有效期）
• 级联删除（删除类型时关联模型也删除）
• 数据验证（Email、手机号格式验证）
• 响应式设计（支持手机、平板、电脑）

=========================================================

四、测试数据说明
--------------
系统已预置：
• 5种模型类型：语言模型、音频模型、视频模型、图像模型、多模态模型
• 6个AI模型示例：
  - GPT-4 (语言模型)
  - Claude 3 (语言模型)
  - Whisper (音频模型)
  - Stable Video Diffusion (视频模型)
  - DALL-E 3 (图像模型)
  - GPT-4V (多模态模型)

=========================================================

五、注意事项
-----------
• 本项目使用SQLite数据库（db.sqlite3）
• 生产环境建议更换为PostgreSQL或MySQL
• 请修改config/settings.py中的SECRET_KEY
• 删除模型类型会级联删除所有关联模型
