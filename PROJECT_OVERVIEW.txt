│                                                                   │
│  ModelType (模型类型) - 外键表                                    │
│  ├── id: 主键                                                     │

│  ├── description: 描述                                            │

│                                                                   │
│  AIModel (AI模型) - 主题表                                        │
│  ├── id: 主键                                                     │
│  ├── name: 模型名称 (字符串)                                      │
│  ├── version: 版本号 (字符串)                                     │
│  ├── description: 描述 (文本)                                     │
│  ├── model_type: 类型 (外键 -> ModelType, CASCADE)               │
│  ├── release_date: 发布日期 (日期)                                │
│  ├── parameters_count: 参数量 (大整数)                            │
│  ├── accuracy_score: 准确率 (小数)                                │
│  ├── training_hours: 训练时长 (整数)                              │
│  ├── is_open_source: 是否开源 (布尔)                              │
│  ├── is_commercial: 是否商用 (布尔)                               │
│  ├── is_active: 是否启用 (布尔)                                   │
│  ├── contact_email: 联系邮箱 (Email)                              │
│  ├── contact_phone: 联系电话 (手机号)                             │
│  ├── developer: 开发者 (字符串)                                   │
│  ├── website_url: 官网 (URL)                                     │
│  ├── created_at: 创建时间 (日期时间)                              │
│  └── updated_at: 更新时间 (日期时间)                              │
