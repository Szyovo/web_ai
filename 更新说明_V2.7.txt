【用户场景】
  1. 用户未登录时访问"创建模型"页面
  2. 系统提示"请先登录才能执行此操作"
  3. 自动跳转到登录页面
  4. 登录成功后，自动跳转回"创建模型"页面
  5. 用户可以直接继续之前的操作

【适用页面】
  ✅ 创建AI模型（/ai-models/create/）
  ✅ 编辑AI模型（/ai-models/edit/<id>/）
  ✅ 删除AI模型（/ai-models/delete/<id>/）
  ✅ 导出CSV（/ai-models/export/）
  ✅ 创建模型类型（/model-types/create/）
  ✅ 编辑模型类型（/model-types/edit/<id>/）
  ✅ 删除模型类型（/model-types/delete/<id>/）
  ✅ 所有使用@login_required_with_message装饰器的页面

【1. 装饰器优化 - decorators.py】

✅ login_required_with_message装饰器
   - 添加next参数传递
   - 使用request.get_full_path()获取完整路径
   - 包含查询参数，确保完整还原用户访问意图

   修改前：
   return redirect('login')

   修改后：
   next_url = request.get_full_path()
   login_url = reverse('login')
   return redirect(f'{login_url}?next={next_url}')

✅ admin_required装饰器
   - 同样添加next参数支持
   - 管理员登录后也能跳转回原页面

【2. 登录视图优化 - views.py】

✅ 安全的跳转逻辑
   - 优先从POST获取next参数（表单提交）
   - 其次从GET获取next参数（URL参数）
   - 添加安全检查，防止开放重定向漏洞

   安全验证：
   1. 检查next_url是否存在
   2. 确保以"/"开头（相对路径）
   3. 确保不以"//"开头（防止协议相对URL）
   4. 如果验证失败，默认跳转到模型列表页

   代码：
   next_url = request.POST.get('next') or request.GET.get('next')
   if next_url and next_url.startswith('/') and not next_url.startswith('//'):
       return redirect(next_url)
   else:
       return redirect('ai_model_list')

【3. 登录模板优化 - login.html】

✅ 添加隐藏字段
   - 将GET参数中的next传递到POST请求
   - 确保表单提交后next参数不丢失

   代码：
   {% if request.GET.next %}
   <input type="hidden" name="next" value="{{ request.GET.next }}">
   {% endif %}

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【防止开放重定向漏洞】

❌ 危险示例：
   https://example.com/login/?next=https://evil.com
   → 登录后跳转到恶意网站

✅ 我们的防护：
   1. 只允许相对路径（以"/"开头）
   2. 不允许协议相对URL（"//"开头）
   3. 验证失败时跳转到安全的默认页面

【验证逻辑】

✅ 合法的next参数：
   /ai-models/create/              → 允许
   /ai-models/edit/5/              → 允许
   /model-types/create/            → 允许
   /ai-models/?page=2              → 允许（包含查询参数）

❌ 非法的next参数：
   https://evil.com                → 拒绝
   //evil.com                      → 拒绝
   javascript:alert('xss')         → 拒绝
   空值或不存在                     → 使用默认页面

   ↓

   ↓
3. 重定向到：http://127.0.0.1:8000/login/?next=/ai-models/create/
   ↓
4. 用户输入用户名密码，点击登录
   ↓
5. 系统验证成功，读取next参数
   ↓
6. 自动跳转到：http://127.0.0.1:8000/ai-models/create/
   ↓

   ↓
3. 登录成功后直接跳转到编辑模型5的页面
